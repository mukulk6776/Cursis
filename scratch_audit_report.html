🔍 In-Depth Finding Details & Technical Remediations

FIND-001: Unverified JWT Fallback Authentication Bypass
CRITICAL RESOLVED
Rule: typescript.jwt.security.unverified-jwt-token-decode File: lib/auth/firebase-admin.ts:78-98 CWE: CWE-287, CWE-347
Strategy 3 in the Firebase token verification chain decoded base64url JWT tokens without verifying the cryptographic signature. An attacker could forge custom JSON tokens with arbitrary user IDs, claim founder or administrator status, and bypass authentication entirely.
Remediation: Completely removed Strategy 3 unverified payload parsing. The authentication chain now strictly requires cryptographic signature validation through Google JWKS or Google's tokeninfo API.
FIND-002: Insecure Voucher Token Prefix Extraction Bypass
CRITICAL RESOLVED
Rule: typescript.auth.security.unverified-session-token-bypass File: app/api/vouchers/redeem/route.ts:23-35 CWE: CWE-287, CWE-345
The voucher redemption handler obtained user credentials by stripping cursis_usr_ from user input without running HMAC-SHA256 signature verification, allowing arbitrary token fabrication to redeem vouchers.
Remediation: Replaced token string manipulation with verifySessionToken(). Authentication now requires valid HMAC-signed tokens matching the secret key.
FIND-003: Client-Side Cookie Write Stripping HttpOnly Flag
HIGH RESOLVED
Rule: javascript.browser.security.insecure-document-cookie-set File: lib/auth/firebase.ts:108 CWE: CWE-1004, CWE-79
Client-side authentication functions wrote cursis_session cookies via document.cookie. This overwrote the server's HttpOnly cookie with a non-HttpOnly browser cookie, allowing XSS scripts to access active session credentials.
Remediation: Removed client-side cookie write statements. Session tokens are strictly managed by server-side headers with HttpOnly: true, Secure: true, and SameSite: 'lax'.
FIND-004: Insufficient Password Complexity Policy
HIGH RESOLVED
Rule: typescript.auth.security.weak-password-policy File: app/api/auth/signup/route.ts:46-57 CWE: CWE-521
User registration permitted passwords as short as 6 characters with no requirement for uppercase, lowercase, numbers, or special symbols, rendering accounts vulnerable to dictionary attacks.
Remediation: Enforced minimum 8-character length with mandatory uppercase, lowercase, numeric, and special character regex rules.
FIND-005: Rate Limiter Fail-Open on Database Outage
HIGH RESOLVED
Rule: typescript.dos.security.rate-limiter-fail-open File: lib/auth/rateLimit.ts:31-101 CWE: CWE-770, CWE-755
When MongoDB connection dropped or suffered transient errors, the rate limiter failed open (returned allowed: true), enabling attackers to flood authentication routes during database outages.
Remediation: Added an in-memory fallback cache that automatically takes over if MongoDB is unreachable, enforcing the 5 attempts / 30 minutes threshold at all times.
FIND-006: Insufficient PBKDF2 Iteration Count
HIGH RESOLVED
Rule: typescript.crypto.security.low-pbkdf2-iteration-count File: lib/db/users.ts:17-31 CWE: CWE-916, CWE-328
User passwords were hashed using only 10,000 iterations of PBKDF2-SHA512. The OWASP 2023 standard recommends at least 600,000 iterations to resist GPU-accelerated hash cracking.
Remediation: Increased PBKDF2 iterations to 600,000 for all newly created passwords and password updates, with backward-compatible verification for existing users.
FIND-007: Open Redirect via Protocol-Relative URLs
MEDIUM RESOLVED
Rule: typescript.nextjs.security.open-redirect-protocol-relative File: proxy.ts:72-76 CWE: CWE-601
The redirect handler in the proxy checked only startsWith('/'), allowing protocol-relative URLs (e.g. //evil.com) or backslash evasions (/\evil.com) to redirect authenticated users off-site.
Remediation: Implemented getSafeRelativeRedirect() ensuring redirect targets strictly start with a single slash, rejecting double slashes, backslashes, CRLF, and null bytes.
FIND-008: Edge WAF Pattern Matching Evasion
MEDIUM RESOLVED
Rule: typescript.waf.security.insufficient-input-sanitization-waf File: proxy.ts:20-53 CWE: CWE-20, CWE-22, CWE-79
The Edge WAF only checked raw URLs, permitting bypasses via URL-encoded characters (e.g. %2e%2e, %00, %0d%0a) and unmonitored injection vectors like <iframe> or event handlers.
Remediation: Added safe URI decoding before inspection, and expanded rules to detect path traversal variations, CRLF injection, null bytes, script tags, dangerous URI schemes, event handlers, and OS probe paths.
FIND-009: Error Message Information Disclosure in API Responses
MEDIUM RESOLVED
Rule: typescript.node.security.error-message-information-disclosure File: lib/api/response.ts:33-48 CWE: CWE-209
Unsanitized 500 responses propagated error.message directly to API callers, risking exposure of MongoDB connection URIs, database credentials, hostnames, and stack traces.
Remediation: Hardened apiError() to automatically sanitize 500 error messages in production and redact database connection strings and sensitive keywords.
FIND-010: Missing Cross-Origin Isolation Headers
MEDIUM RESOLVED
Rule: typescript.nextjs.security.missing-coop-corp-headers File: next.config.ts:66-74, proxy.ts CWE: CWE-693
The application lacked Cross-Origin-Opener-Policy (COOP) and Cross-Origin-Resource-Policy (CORP) headers, leaving the application open to cross-origin process-sharing attacks.
Remediation: Added Cross-Origin-Opener-Policy: same-origin and Cross-Origin-Resource-Policy: same-origin in both next.config.ts and the Edge proxy headers.
FIND-011: React Strict Mode Disabled in Configuration
LOW RESOLVED
Rule: typescript.react.security.react-strict-mode-disabled File: next.config.ts:4 CWE: CWE-693
reactStrictMode: false disabled React lifecycle warnings, memory leak checks, and legacy API detection.
Remediation: Enabled reactStrictMode: true in next.config.ts.
FIND-012: Anonymous Promo Code Redemption & Rate Limit Absence
MEDIUM RESOLVED
Rule: typescript.api.security.unauthenticated-promo-code-consumption File: app/api/redeem/route.ts:74-120 CWE: CWE-306, CWE-799
The /api/redeem route allowed unauthenticated callers to consume promo codes, burning codes for anonymous users, and lacked IP rate limiting.
Remediation: Enforced user authentication prior to redemption and added rate limiting with IP attempt tracking to protect promo vouchers.
FIND-013: Database Diagnostics Connection URI Redaction
MEDIUM RESOLVED
Rule: typescript.api.security.database-diagnostics-credential-leak File: app/api/db-status/route.ts:47-58 CWE: CWE-200, CWE-209
Database error responses in /api/db-status could include raw connection URIs when MongoDB connectivity failed.
Remediation: Added regex-based URI stripping that sanitizes username/password credentials and masks connection strings in error outputs.
